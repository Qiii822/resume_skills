# 公司类型 → 简历风格倾向 对照参考

> Step 3 重写语气时查阅本文件。公司类型不是绝对的，若 JD 实际措辞与下表冲突，以 JD 措辞为准。

## 大厂 / 外企（如 Microsoft、Google、传统 500 强、大型外资）

- **语言正式程度**：高。用词规范、克制，少用口语化 / 网络化表达；英文简历注意时态与专业术语。
- **是否偏好量化数据**：强偏好。成果尽量用数字说话（比例、规模、金额、时长）。
- **是否偏好突出主动性 / 多面手能力**：中等。更看重在明确职责范围内的专业深度与协作 / 流程意识，
  而非"什么都干过"。主动性体现在"发现问题并推动解决"，而非"一个人扛下所有"。
- **排版偏好**：简洁、克制。清晰的信息层级，少用花哨图标 / 配色，强调可读性与专业性。

## 创业公司 / 早期团队

- **语言正式程度**：中偏低。语气更直接、有冲劲，可用结果导向的动词（打造、从 0 到 1、落地、扛起）。
- **是否偏好量化数据**：偏好，但更看重"冷启动 / 从 0 到 1 / 快速迭代"的过程叙事，数字服务于增长故事。
- **是否偏好突出主动性 / 多面手能力**：强偏好。突出 owner 心态、跨职能、在资源有限下推进的能力。
- **排版偏好**：可稍微有设计感，但仍以信息清晰优先；可适度用粗体 / 分区强调关键成果。

## 国企 / 事业单位

- **语言正式程度**：高且偏公文 / 稳重。措辞严谨、规范，避免激进或夸张表述。
- **是否偏好量化数据**：中等。数字有帮助，但更看重资历、稳定性、合规与流程规范，而非"增长黑客"式成果。
- **是否偏好突出主动性 / 多面手能力**：弱。更看重可靠、服从安排、长期稳定、在体系内踏实执行。
- **排版偏好**：简洁、庄重，避免设计感过强或花哨。

## 互联网大厂（如 BAT、字节、美团等国内头部）

- **语言正式程度**：中。规范但不刻板，鼓励简洁、结果导向的表达，可适度使用行业通用术语（闭环、owner、复盘）。
- **是否偏好量化数据**：强偏好。极其看重可量化的业务结果与影响面（DAU、转化率、性能提升、GMV 等）。
- **是否偏好突出主动性 / 多面手能力**：偏好。突出 owner 意识、主动推进、跨团队协作与扛指标的能力。
- **排版偏好**：简洁、信息密度高；一页内塞下更多量化成果，避免无意义留白。

## AI / 科技初创

- **语言正式程度**：中。专业术语可稍多（模型、推理、pipeline、评测等），但要准确，不堆砌。
- **是否偏好量化数据**：强偏好。既包括技术指标（准确率、延迟、吞吐、QPS），也包括落地影响（用户数、成本下降）。
- **是否偏好突出主动性 / 多面手能力**：强偏好。尤其看重"从想法到落地"的完整闭环、快速实验、对前沿技术的敏感。
- **排版偏好**：可稍现代、有设计感（尤其投递偏产品 / 设计的角色），但技术岗仍以清晰、专业为准。

---

## 通用原则（跨类型都适用）

- 无论哪类公司，**真实、可验证**永远优先于"看起来匹配"。
- 量化数据能写就写；不能写就写清楚做了什么、解决了什么问题，**不编造**。
- 术语对齐 JD 的表述，但只在语义一致时替换，**不强行套用**。
